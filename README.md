# yaygames

yaygames is a fantasy console that runs games ranging from pico 8, to html5

## how to add games
simple email nexusternot@gmail.com and request a game
if it is your game, provide one of these:
- an index.html file,
- zip that contains an index.html,
- or p8.png cart ( those are handled seperately )

it is a likely yes, as long as those games are appropriate for people under 18
